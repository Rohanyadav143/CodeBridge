# 🚀 CodeBridge

**CodeBridge** is a modern online coding interview and hiring platform that enables companies to assess developers through real-time coding challenges and technical evaluations. It is designed to streamline the technical hiring process with an intuitive interface, secure assessments, and scalable architecture.

## 🌟 Overview

CodeBridge provides a seamless environment where recruiters can create coding assessments and evaluate candidates based on their problem-solving skills. Candidates can participate in coding tests in a distraction-free environment while recruiters receive detailed evaluation results.

## 🚀 Getting Started

### Clone the Repository

```bash
git clone https://github.com/Rohanyadav143/CodeBridge.git
cd CodeBridge
```

### Install Dependencies

#### Frontend

```bash
cd client
npm install
npm run dev
```

#### Backend

```bash
cd server
npm install
npm run dev
```
